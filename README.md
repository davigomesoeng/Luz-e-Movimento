# Luz e Movimento em Paralelo
Projeto 5 — Distribuição de energia com cargas diferentes, desenvolvido no Tinkercad.

## Como nasceu este projeto
Não segui um tutorial completo. Vi os componentes no Tinkercad, entendi onde cada um se conectava, e fui montando por conta própria até funcionar. Sem saber exatamente para que serviria — só com curiosidade de ver o que aconteceria.

## Circuito
- Fonte: 2 pilhas AA de 1,5 V em série → 3,0 V total
- 2 lâmpadas em paralelo
- 1 motor CC em paralelo com as lâmpadas
- Circuito montado completamente por conta própria, sem seguir passo a passo

## Medições
- Tensão da fonte: 3,0 V (teórica)
- Tensão medida: 2,76 V (queda normal nos componentes e conexões)
- Velocidade do motor: 94 RPM
- Resultado: ✅ As lâmpadas acenderam e o motor girou — tudo funcionando ao mesmo tempo

## O que aprendi sozinho
- Em paralelo, todos os dispositivos recebem a mesma tensão
- Mesmo sendo tipos diferentes — lâmpada e motor — funcionam juntos sem um atrapalhar o outro
- O motor também é uma carga: consome corrente igual às lâmpadas
- Se um dispositivo parar, os outros continuam funcionando
- Isso é basicamente como funciona a rede elétrica de uma casa

## Conclusão
Não esperei saber tudo para começar. Observei, tentei, ajustei e vi funcionar. A curiosidade de testar sem ter todas as respostas antes é parte de como se aprende de verdade.
